Selected Work

Open source · Information extraction

CS Baoyan Chat Daily

Useful information, out of busy group chats.

An LLM-powered tool that turns CS graduate admissions discussions into structured daily digests, helping readers find application information and follow the conversation without reading every message.

Combines anonymization, evidence-linked extraction, and structured summaries in a pipeline others can deploy themselves.

Browse past digests ↗ 78 GitHub stars ↗

The public digest is now an archive; the generation tool remains available for self-hosting.

Evaluation · Multimodal AI

RTV-Eval

Reproducible experiments for video-language models.

How much visual input does a model need? I built an evaluation framework to compare frame sampling, resolution, and content-adaptive strategies under controlled configurations.

The pipeline retains raw responses, validates answers, and checkpoints results in SQLite, making experiments resumable and their results easier to inspect and analyze.

Explore the framework ↗

Offline evaluation of video input strategies; not an end-to-end real-time streaming benchmark.

AI application · Automation

EigenDigest

From scattered sources to a readable digest.

An information bot that brings RSS feeds, web articles, and public-account content into one workflow. It removes duplicates, generates concise summaries with an LLM, and delivers scheduled subscription digests.

About

I like working on problems where AI can make everyday information easier to use. That means building the whole path from a model's output to a tool that fits into someone's day.

I also enjoy the experimental side: asking what actually works, checking the evidence, and making the process reproducible enough for others to build on.
